# Relay

## Register

product

## Users

People running one or several Codex terminal sessions on a Mac, including friends installing Relay for the first time.

## Product Purpose

Keep saved tasks moving through account resets and temporary failures, with visible status and faithful permissions. The menu bar is a quiet way to check accounts and return to work.

## Brand Personality

Clear, quiet, dependable. Use the existing Relay identity and everyday language.

## Anti-references

Avoid jargon, promotional filler, decorative dashboard cards, repeated terminal output, and a text label consuming menu-bar space.

## Design Principles

- Show whether recovery is active and what happens next.
- Treat permission choices and review holds as durable user decisions.
- Use familiar macOS controls and a recognizable monochrome icon.
- Refresh local state when it changes; fetch allowance only when needed or requested.
- Keep failures actionable and show the age of cached information.

## Accessibility & Inclusion

Use native system fonts, keyboard navigation, VoiceOver labels, and system light/dark appearance. State must be conveyed in text as well as the icon. Respect reduced motion; no decorative animation.
